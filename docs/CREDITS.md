# 素材來源

全部素材同工具都係免費。

## 材質（Poly Haven，CC0）
monastery_stone_floor、castle_wall_slates、mossy_cobblestone、mossy_stone_wall、stone_tiles_02、rock_wall_08、cobblestone_floor_04、plastered_stone_wall、medieval_wood、grey_roof_tiles

## 道具模型（Poly Haven，CC0）
wooden_crate_01、treasure_chest、wooden_candlestick、Lantern_01、wine_barrel_01、wooden_bucket_01、WoodenTable_01、WoodenChair_01、painted_wooden_bench、gothic_statue、dead_tree_trunk、wooden_barrels_01

## 角色模型
MakeHuman 人體、皮膚、頭髮素材（CC0），用 MPFB 2.0.18（GPL，只係工具）喺 Blender 4.2 生成；裝備由 `scripts/blender/make_character.py` 按身體模型砌出嚟

## 角色動作
Quaternius Universal Animation Library 1、2（CC0）。只用動作，冇用佢嘅模型

## 裝備材質（ambientCG，CC0）
Leather026、Metal034、Fabric030

## 圖示同頭像
本機 ComfyUI + Stable Diffusion XL 1.0 生成（`scripts/gen-icons.mjs`、`scripts/gen-portraits.mjs`）

## 音效
全部用 Web Audio 即場合成（`src/audio/sound.ts`），冇用音效檔

## 字體
Noto Serif TC、Cinzel（Google Fonts，SIL Open Font License）

## 程式庫
three.js、postprocessing、n8ao（MIT）
