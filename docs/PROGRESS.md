# 開發進度

## Phase 0 — 風格驗證場景（等用戶確認）

**計劃：** Vite + Three.js + TS 專案、PBR 地牢房間、4 支閃爍火把、Poly Haven 道具、寫實人型角色點擊移動、完整燈光同後期效果、3 張截圖。

**做咗：**
- 房間：PBR 石地、石牆、壁柱、方柱、斷柱、祭台（全部有倒角，貼 albedo / normal / roughness / AO）
- 道具：Poly Haven 真實模型（寶箱、酒桶、木箱、木桶、燈籠、蠟燭）
- 主角：Soldier.glb 暫代，滑鼠點擊移動，idle / walk / run 切換
- 燈光：極低環境光、主角暖光（唯一投影燈）、4 支閃爍火把、祭台燭光、霧
- 後期：ACES、N8AO、Bloom、調色、暗角、底片顆粒、SMAA
- 粒子：火星、灰塵
- 畫質：網址加 `?q=low`、`?q=medium`、`?q=high`（選單留待 Phase 7）

**檢查結果：**
- 第 0.1 節：冇用幾何體做角色或道具，冇卡通素材，畫面夠暗
- 1920×1080 冇捲動；真滑鼠點擊移動正常
- FPS（Intel UHD 內置顯示卡，1920×1080）：low 28、medium 10.7、high 6.7

**已知問題：**
- 內置顯示卡 low 畫質 28 FPS，略低於 30 FPS 目標；medium / high 遠低於 60。呢部機未測到獨立顯卡
- 主角係現代士兵暫代，唔係正式獵魔人
- 火把暫用燈籠模型代替，火焰近睇偏白、形狀簡單
- 未有尋路，撞到障礙會停（Phase 1 做 A*）
