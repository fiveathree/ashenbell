# 開發進度

## Phase 0 — 風格驗證場景（等用戶確認）

**計劃：** Vite + Three.js + TS 專案、PBR 地牢房間、4 支閃爍火把、Poly Haven 道具、寫實人型角色點擊移動、完整燈光同後期效果、3 張截圖。

**做咗：**
- 房間：PBR 石地、石牆、壁柱、方柱、斷柱、祭台（全部有倒角，貼 albedo / normal / roughness / AO）
- 道具：Poly Haven 真實模型（寶箱、酒桶、木箱、木桶、燈籠、蠟燭）
- 主角：Soldier.glb 暫代，滑鼠點擊移動，idle / walk / run 切換
- 燈光：極低環境光、主角暖光（唯一投影燈）、4 支閃爍火把、祭台燭光、霧
- 後期：ACES、N8AO、Bloom、調色、暗角、底片顆粒、SMAA
- 粒子：火星、灰塵
- 畫質：網址加 `?q=low`、`?q=medium`、`?q=high`（選單留待 Phase 7）

**檢查結果：**
- 第 0.1 節：冇用幾何體做角色或道具，冇卡通素材，畫面夠暗
- 1920×1080 冇捲動；真滑鼠點擊移動正常
- FPS（Intel UHD 內置顯示卡，1920×1080）：low 28、medium 10.7、high 6.7

**已知問題：**
- 內置顯示卡 low 畫質 28 FPS，略低於 30 FPS 目標；medium / high 遠低於 60。呢部機未測到獨立顯卡
- 主角係現代士兵暫代，唔係正式獵魔人
- 火把暫用燈籠模型代替，火焰近睇偏白、形狀簡單
- 未有尋路，撞到障礙會停（Phase 1 做 A*）

用戶已確認 Phase 0 畫面質感。

## Phase 1 — 核心操作同戰鬥（完成）

**計劃：** 格仔地圖、A* 尋路、點擊同按住移動、相機跟隨同縮放、屍鬼 AI、主角普通攻擊、生命、死亡復活、HUD。

**做咗：**
- `src/world/grid.ts`：0.5m 格仔、A*（唔切角）、路徑拉直、視線判斷
- 撳地面行、撳怪攻擊、按住持續；滾輪縮放、相機平滑跟隨
- 屍鬼：待機、發現、追擊、攻擊、受擊白閃硬直、倒地、屍體 10 秒後淡出
- 主角：攻擊、傷害公式（第 6.4 節）、生命 150、怒氣、死亡、3 秒後復活
- HUD：血球、怒氣球、技能欄（空）、經驗條、任務提示、指住怪物顯示血條
- 測試房間：殺夠 10 隻過關，清完會再出一批

**驗收：**
- 真滑鼠打測試房間：27 秒殺 10 隻，主角剩 126/150 血
- 死亡同復活：測試通過
- Vitest：7 個測試通過（尋路、傷害公式）
- 未達標：FPS 見下面

**已知問題：**
- 60 FPS 未驗到：呢部機只有 Intel UHD 內置顯示卡，打鬥時 low 約 22 FPS，規格要內置顯示卡 30 FPS；獨立顯卡未測
- 屍鬼同主角都係 Soldier.glb 暫代，屍鬼只係染暗綠
- 攻擊同倒地動作係程式轉骨頭嘅暫代，冇武器模型；有 Mixamo 動作後刪走 `src/entities/pose.ts`
- 血濺、血跡貼花、傷害浮字留待 Phase 3

## Phase 2 — 地城生成（完成）

**計劃：** 隨機地城、三層主題材質、上落樓梯、火把同道具自動擺放、可打破道具、小地圖、迷霧探索、Tab 大地圖。

**做咗：**
- `src/world/dungeon.ts`：seed 固定嘅房間 + 最小生成樹走廊 + 迴路，每層 12–20 間房，房型有入口、出口、普通、祭壇、寶箱、精英
- 擺完道具會檢查每間房都行得到，唔通就重新生成
- 三層主題：地窖墓穴、淹沒禮拜堂（淺水減速）、封印之井（紅色符文）
- 樓梯：撳樓梯自動行過去上落，第 1 層上樓梯要等 Phase 5 小鎮
- 火把、柱、道具、屍鬼自動擺放；撳木桶、木箱、水桶可打破，有機會得金幣
- 小地圖、迷霧探索、Tab 大地圖
- 光源池：燈數固定，只搬去最近嘅火把，轉燈時唔會卡
- 模型減面：蠟燭原本 21 萬面，減到 12%；材質轉 1K webp，素材總量 12MB

**驗收：**
- 同一 seed 重開網頁，三層地圖完全相同
- 三層截圖：`docs/screenshots/phase2-floor1.png`、`phase2-floor2.png`、`phase2-floor3.png`，大地圖 `phase2-map.png`
- 真滑鼠打破道具、落樓梯：通過
- Vitest：12 個測試通過

**效能（Intel UHD，1920×1080）：**
| 畫質 | FPS | Draw calls |
|---|---|---|
| low | 19–31 | 107–132 |
| high | 5–8 | 243–309 |

**已知問題：**
- high 畫質最多 309 draw calls，略超 300 目標
- 第 1、3 層 low 畫質未達 30 FPS；60 FPS 未有獨立顯卡驗證
- 走廊經過嘅光會穿牆，因為火把唔投影
- 棺材、骸骨、破長椅、鎖鏈未有免費合適模型，三層暫時用木桶木箱；第 3 層 Boss 房留待 Phase 6
- 所有樓層暫時只有屍鬼，其他怪物留待 Phase 3
